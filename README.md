# 化工推免估分器

沈阳化工大学化学工程学院第一版静态网站，使用 GitHub Pages 部署。

## 当前功能

- 复制教务系统表格，自动识别课程、学分、成绩和实践成绩
- 浏览器本地 OCR 识别成绩单照片，识别后可人工核对
- 手动新增课程
- 按当前规则计算学分加权平均分
- 计算“学业分 90% + 综合能力成绩 10%”的估算总分
- 导入、导出匿名样本，估计同专业同年级样本内排名
- 导出课程计算明细 CSV

## 当前规则模板

- 纳入：必修、实践、实践环节；课外实践仅在非选修归属时纳入
- 排除：选修、任意任选、经济管理类，以及归属为专业选修课的课外实践
- 优秀 / 良好 / 中等：95 / 85 / 75
- 通过：75
- 学分加权平均分：`Σ(学分 × 折算成绩) ÷ Σ学分`

## 本地运行

在 `site` 目录启动任意静态服务器，例如：

```bash
python -m http.server 4173 --directory dist
```

浏览器打开 `http://localhost:4173`。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `sycce-baoyan-estimator`。
2. 将本目录内容推送到仓库的 `main` 分支。
3. GitHub Actions 会使用 `.github/workflows/deploy.yml` 自动部署。
4. 在仓库 Settings → Pages 中确认 Source 使用 GitHub Actions。

第一版的样本池保存在用户浏览器的 `localStorage`。如果需要所有同学共享并实时计算排名，需要下一版接入数据库和匿名提交接口。
